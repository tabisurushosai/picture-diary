# プライバシーポリシー / Privacy Policy — えにっき (Picture Diary)
## 日本語
本拡張機能は日記データや個人情報を収集・送信しません。日記データは chrome.storage.local 内にのみ保存されます。ユーザーが購入ボタンを押した場合のみ、支払い手続きのため Stripe Checkout を新しいタブで開きます。トラッキング・広告・第三者提供はありません。拡張機能を削除すると保存データも削除されます。
## English
This extension does not collect or transmit diary data or personal data. Diary data is stored only in chrome.storage.local. Only when the user clicks the purchase button, the extension opens Stripe Checkout in a new tab for payment. No tracking, ads, or sharing. Uninstalling removes all stored data.
